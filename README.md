# JamReport
JamReport é um sistema Web que importas seu relatório criado no AWS Skill Builder de um SImulado de JAM feito pelo competidor  e gera um relatório mais robusto  e direto em relação ao que é apresentado na plataforma, além de ter como principal objetivo acompanha de forma  geral seu competidor em relação aos demais.  Leia mais no README
